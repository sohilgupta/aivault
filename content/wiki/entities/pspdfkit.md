# PSPDFKit

**Type:** Software company / SDK
**Founded by:** [[wiki/entities/peter-steinberger]]
**Tenure:** 13 years
**Scale:** Used on ~1 billion devices
**Fate:** Sold (details not disclosed in source)

## Overview

PSPDFKit was a PDF rendering and annotation SDK, primarily for iOS and Android, built by Peter Steinberger. It became one of the most widely deployed PDF libraries in mobile software history, used on approximately a billion devices.

Peter built it after trying and failing to display a PDF on an iPad — a trivially-sounding problem with no good existing solution at the time. This "why doesn't this exist?" instinct recurred in the creation of [[wiki/entities/openclaw]].

## Significance

PSPDFKit is the origin point of Peter's engineering values: solve hard problems, ship with love, focus on delight over features, be comfortable running a long (13-year) focused project. The burnout from PSPDFKit (from people management, co-founder conflicts) led to his sabbatical and eventual return via OpenClaw.
