## Concepts
| Page | Summary |
|------|---------|
| [[wiki/concepts/agentic-engineering]] | Disciplined practice of directing AI agents with architectural context and empathy; contrasted with "vibe coding" |
| [[wiki/concepts/agentic-loop]] | Core runtime pattern of any agent system: input → LLM+tools → execute → repeat → respond |
| [[wiki/concepts/mcps-vs-skills]] | CLIs + skills beat MCPs because they compose naturally, don't pollute context, and use weights the model already knows |
| [[wiki/concepts/personal-agents]] | AI with persistent access to your data/devices; 2026 convergence from Peter, Sam Altman, and Sundar Pichai on the same vision |
| [[wiki/concepts/ai-psychosis]] | Public tendency to uncritically trust or catastrophically fear LLM outputs; also: Claude Code psychosis (productivity-euphoric variant) |
| [[wiki/concepts/soul-md]] | Persistent agent identity document; written partly by the agent itself; philosophical anchor and personality source |
| [[wiki/concepts/prompt-injection]] | Open security problem: malicious content in agent inputs overriding goals; mitigated by smart models, sandboxing, allow-lists |
| [[wiki/concepts/tokenomics]] | Economics of AI token supply and demand; who gets access, at what price, what value they generate; every supply layer sold out |
| [[wiki/concepts/ai-permanent-underclass]] | Dylan Patel's framing: those who fail to use/generate/capture value from tokens will be structurally disadvantaged |
| [[wiki/concepts/phantom-gdp]] | Economic value created by AI productivity that is invisible to standard GDP statistics; coined by SemiAnalysis economist Malcolm |
| [[wiki/concepts/scaling-laws]] | More compute into model makes model better; still holding as of 2026; Mythos (L6 engineer) + Dario's exponential thesis as proof |
| [[wiki/concepts/ai-diffusion]] | The propagation of AI capability into economic/org use; capability and diffusion are two separate curves; 2027 enterprise inflection |
| [[wiki/concepts/biological-revolution]] | Dario Amodei's thesis: AI compresses decades of biomedical progress into years; primary motivating vision for Anthropic's mission |
| [[wiki/concepts/llm-nature]] | Karpathy's reframe: LLMs are ghosts summoned from the human corpus, not novel intelligences; explains capabilities and deficits |
| [[wiki/concepts/post-scaling-research]] | Ilya's thesis: after the internet data wall, algorithmic insight (not compute) becomes the differentiating skill; age of research |
| [[wiki/concepts/ai-sovereignty]] | Geopolitical dimension of AI deployment: trust, data residency, concentration risk, open source as structural check |
| [[wiki/concepts/agi-timeline]] | Cross-source comparison of AGI timeline predictions: 2027 (Leopold), 1-2yr (Dario), not far (Sam); intelligence explosion implications |
| [[wiki/concepts/non-deterministic-software]] | AI-powered software produces variable outputs for identical inputs; shifts quality ownership from spec-writing to evals; judgment is the remaining human skill |
